## 决策

建立一个可公开发布、双语、规范优先的仓库，并完成一条可确定性验证和构建的纵向链路。本阶段不对外发布或推送。

## 目标

- 建立产品、治理、安全、许可、贡献和交接事实；
- 定义节点、实体、声明、引用和目录 Schema 草案；
- 无需专有服务即可校验示例和试点源文件；
- 生成确定性的 JSON/JSONL 制品；
- 添加只读 CI 和结构化 Issue/PR 模板。

## 非目标

- 填充真实领域目录；
- 实现联邦、语义搜索、爬虫、托管 API 或外部写入；
- 创建 GitHub 远程地址、组织、Release、Tag 或公开网站；
- 宣称协议稳定或可用于生产。

## 不变量

- 缺失、不可用、过期、争议和否定必须保持可区分；
- 声明保留来源、方法、观测时间和状态；
- 英文与简体中文规范文档保持配对；
- 核心校验无需密钥或专有服务即可在本地运行；
- 生成制品不得手工维护。

## 目标数据流

```text
Schema + 示例 + 试点源文件
              ↓
         本地语义校验器
              ↓
         确定性构建器
              ↓
            dist/*
              ↓
         测试与只读 CI
```

## 状态与失败语义

| 状态/事件 | 结果 | 恢复方式 |
|---|---|---|
| JSON 无效 | 校验失败并显示路径 | 修正源文件 |
| 缺少引用 | 声明被拒绝 | 增加证据或表达为未知 |
| 实体 ID 重复 | 阻止构建 | 明确解决实体身份 |
| 缺少翻译对应文件 | 校验失败 | 新增或更新对应文件 |
| 没有试点条目 | 生成有效空草案目录 | 后续添加审核条目 |
| 外部链接不可用 | 本地契约检查仍可运行，但来源新鲜度未知 | 单独重试并将来源标记为不可用 |

## 安全与隐私

- 读取数据：仅仓库已提交文件；
- 禁止数据：密钥、私人令牌、私人个人数据、无许可的样例副本；
- 副作用：仅生成本地 `dist/`；
- 对外发布：必须获得维护者明确授权。
