# 数据与证据原则

简体中文 | [English](data-principles.md)

## 保存声明，不保存“真相单元格”

一条记录表示：“来源 S 在限定条件 Q 下支持主体 P 的值 V，节点在时间 T 进行了观测。”它不表示项目宣称 V 在所有情况下都是真理。

## 必须区分的概念

- **实体：** 使用稳定标识符的持久主体；
- **声明：** 关于实体的属性和值；
- **限定条件：** 改变适用范围或解释的上下文；
- **引用：** 可检查的证据及检索元数据；
- **方法：** 节点如何产生或审核声明；
- **状态：** 当前证据生命周期状态。

## 证据质量

- 发布者能力和政策优先使用直接的一手来源；
- 二手来源应提供独立观测或分析；
- 社区报告和机器提取必须明确标记；
- 可获得时保留精确来源位置和修订版本；
- 只保存必要的最小摘录，默认不镜像第三方作品。

## 时间语义

- `observed_at`：节点检查证据的时间；
- `valid_from`：已知情况下声明开始适用的时间；
- `valid_until`：已知情况下声明停止适用的时间；
- `retrieved_at`：特定引用被获取的时间。

最新观测不一定就是最佳声明。只要范围和状态明确，历史或被替代声明仍可能有价值。

## 失败语义

| 情况 | 必须采用的表达 |
|---|---|
| 来源无法访问 | 标记检索不可用；政策允许时保留上次观测并标记过期 |
| 未找到证据 | 标记未知或没有观测，禁止编造否定值 |
| 来源冲突 | 保留不同声明，标记争议或范围差异 |
| 机器提取不确定 | 标记方法与置信信息，不得设为已核验 |
| 来源删除陈述 | 记录撤回或新观测，同时保留历史 |

## 隐私与安全

信息公开并不意味着项目应收集敏感个人数据。试点接受个人级记录前，必须定义收录、保留、脱敏与删除规则。
