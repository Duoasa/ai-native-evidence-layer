# ADR-0002：采用以声明为中心的证据模型

简体中文 | [English](0002-claim-centric-evidence-model.md)

状态：已接受
日期：2026-08-28

## 背景

扁平实体记录容易形成“最后写入者覆盖”机制，并隐藏来源分歧、时间、范围和提取方法。

## 决策

知识表示为实体及其拥有独立 ID 的声明。每条声明包含属性、值、方法、观测时间、生命周期状态、可选限定条件和一个或多个引用。

## 考虑过的替代方案

- **扁平记录：** 查询简单，但会丢失来源和冲突语义；
- **自由文档：** 表达丰富，但迫使 AI 消费者反复重建结构；
- **立即完整兼容 RDF/Wikibase：** 成熟但对首条纵向链路过于庞大。

## 后果

- 正面：声明级引用、带范围的冲突、明确时间、可审核的机器提取；
- 权衡：记录更冗长，对编辑工具要求更高；
- 后续：测试草案能否干净映射到成熟关联数据格式，但不把映射作为 v0.1 要求。
