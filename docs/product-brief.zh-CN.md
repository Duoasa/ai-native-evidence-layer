## 产品承诺

让独立信息发布者能够向 AI 系统提供结构化声明，并持续保留声明的来源、时间、适用范围、验证状态和可迁移性。

## 核心用户与任务

- **AI 应用开发者：** 无需抓取面向展示的网页即可检索证据；
- **领域目录维护者：** 发布可信、带版本、机器可读的记录；
- **信息发布者：** 在保留身份与版本上下文的前提下声明自身能力；
- **研究者与审核者：** 检查 AI 可用声明为何存在，并用证据提出质疑。

## 首个完整版本

- 发布带来源、时间、范围和状态语义的声明型 Schema 草案；
- 将一个狭窄试点目录从源文件确定性构建为 JSON 与 JSONL；
- 仅使用生成目录完成一组小型基准问题，并保留声明来源；
- 记录可由独立 Fork 重现的贡献、争议、迁移和发布流程。

## 首个版本非目标

- 索引整个互联网；
- 建立唯一的中心化真相权威；
- 支持私人或敏感个人数据集；
- 自主对外部系统执行写操作；
- 提供通用爬虫、向量数据库或托管商业服务；
- 在单节点试点证明语义前稳定联邦协议。

## 约束

- **分发：** 公开 Git 仓库、确定性静态导出、可自托管工具；
- **隐私与安全：** 不含密钥和私人个人数据，明确信任边界；
- **运维：** 一名维护者也能完成校验、发布和交接；
- **兼容性：** Schema 带版本，已发布版本不可变，迁移必须明确；
- **本地化：** 面向用户的规范文档同时提供英文和简体中文。

## 成功证据

- 克隆仓库后，无需专有服务即可完成全部校验；
- 每条关键试点声明至少拥有一个可检查来源；
- 缺失、不可用、过期、争议与否定状态保持可区分；
- 生成制品可由提交的源文件确定性重建；
- 第二个实现无需私下指导即可消费已发布 Schema。

## 仍需维护者决定

- 确认或替换“科研信息源”试点；
- 发布首个非示例目录前决定数据开放许可；
- 首次公开发布前确定维护者联系渠道。
