# Schema v0.1 working draft / Schema v0.1 工作草案

## English

This directory contains pre-release JSON Schema contracts for nodes, entities, claims, references, and catalog snapshots. Version `0.1.0` is not stable and may change incompatibly before the first tagged protocol release.

The semantic unit is a claim, not a flattened truth field. Consumers must preserve qualifiers, references, method, observation time, and lifecycle state. Relative `$ref` values resolve within this directory.

## 简体中文

本目录包含节点、实体、声明、引用和目录快照的预发布 JSON Schema。版本 `0.1.0` 尚不稳定，在首个带标签的协议发布前可能发生不兼容变化。

语义基本单位是声明，而不是扁平的真相字段。消费者必须保留限定条件、引用、方法、观测时间和生命周期状态。相对 `$ref` 在本目录内解析。
