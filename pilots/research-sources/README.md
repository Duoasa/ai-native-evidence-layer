# Research information sources pilot / 科研信息源试点

## English

Status: **Proposed.** This pilot is a test domain for the core evidence model. It does not yet contain approved real entries and has not been released.

Source entity JSON files belong in `catalog/`. Inclusion rules, freshness policy, and data licensing must be approved before real data is published.

## 简体中文

状态：**提议中。** 本试点用于验证核心证据模型，目前没有经过批准的真实条目，也没有发布。

实体源 JSON 文件应放在 `catalog/`。真实数据发布前必须批准收录规则、时效政策和数据许可。
