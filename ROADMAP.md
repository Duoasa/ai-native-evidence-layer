# Roadmap

[简体中文](ROADMAP.zh-CN.md) | English

The roadmap communicates intent, not release status.

## Phase 0 — Repository foundation

- Bilingual project, governance, security, and contribution rules.
- Draft claim-centric schemas.
- Dependency-free validator, deterministic builder, tests, and CI.
- Explicit handoff and architecture decisions.

## Phase 1 — One coherent pilot

- Confirm one narrow domain and its inclusion policy.
- Publish 20–30 reviewed entities with claim-level references.
- Generate JSON, JSONL, node metadata, and change artifacts.
- Demonstrate ten benchmark questions answered from the catalog.

## Phase 2 — Sustainable contribution

- Review workflow for additions, corrections, disputes, and staleness.
- Schema migration and catalog snapshot process.
- Static human-facing explorer generated from the same source data.
- First external contributor onboarding.

## Phase 3 — Federation experiment

- Node discovery and namespace rules.
- Cross-node identity and conflict-preserving aggregation.
- Conformance fixtures and an independent second implementation.

## Phase 4 — First stable protocol

- Compatibility policy and supported versions.
- Security and privacy threat model.
- Signed release artifacts and migration documentation.
- Stable protocol `1.0` only after independent interoperability evidence.
