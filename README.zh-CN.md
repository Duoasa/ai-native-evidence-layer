# AI 原生分布式互联网知识与证据层

简体中文 | [English](README.md)

> 让 AI 获取的每一条信息，都知道它是什么、来自哪里、何时有效。

本仓库是“AI 原生分布式互联网知识与证据层”的开放启动点。项目定义可互操作的数据契约、校验工具、治理规则和小领域参考试点，使独立主体能够发布带有来源、时间、适用范围与验证状态的结构化声明。

项目不是一个中心化的“全球真相数据库”，而是一套让独立节点能够发布、迁移、比较和验证信息的开放基础设施。

## 设计原则

- **证据先于权威：** 关键声明必须指向可检查的来源。
- **保留分歧，不静默覆盖：** 冲突声明可以并存，但必须明确范围与状态。
- **时间属于语义：** 观测时间、生效时间、失效时间和撤回时间不能混为一谈。
- **开放与可迁移：** Schema、工具和生成格式不绑定单一 AI 厂商。
- **从结构上支持分布式：** 任何主体都可以实现或运行兼容节点。
- **自动化必须可追责：** 机器提取结果必须标记，不能静默升级为已核验事实。
- **隐私最小化：** 节点只收集其声明领域所必需的数据。

## 概念架构

```text
信息发布者与维护者
        ↓
独立证据节点
        ↓
开放 Schema 与交换格式
        ↓
索引、校验与冲突感知聚合
        ↓
AI 检索与推理
        ↓
带来源、时间、范围和不确定性的答案
```

## 仓库结构

```text
schema/        带版本的机器可读契约
pilots/        用于验证契约的小领域试点
examples/      不进入生产目录的示例
scripts/       零外部依赖的校验与构建工具
tests/         契约与失败语义测试
docs/          产品、架构、治理与决策文档
dist/          可重复生成的机器制品
.github/       贡献模板与持续校验
```

## 快速开始

环境要求：Node.js 24、npm 11 或更高版本。

```bash
npm ci
npm run check
```

常用命令：

```bash
npm run validate   # 校验 Schema、示例、试点数据和双语覆盖
npm test           # 验证语义规则与失败情况
npm run build      # 重新生成目录、JSONL、节点元数据与变化记录
npm run check      # 执行完整的本地验证门禁
```

## 首个试点

当前提议的第一个试点是“小型科研信息源目录”。它用于验证证据模型，并不限定项目的永久范围。试点条目必须遵守未来节点同样的来源与状态规则。
