# Support

[简体中文](SUPPORT.zh-CN.md) | English

This project is in bootstrap and has no service-level agreement.

- Use issue forms for reproducible bugs, data corrections, and schema proposals.
- Use pull requests for reviewable fixes.
- Use GitHub Discussions for open-ended design questions once Discussions are enabled.
- Use the private security process for vulnerabilities.

Please do not send private datasets, credentials, or confidential organization details as support material.
